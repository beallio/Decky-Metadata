# Install Decky Metadata

Decky Metadata runs on a Steam Deck in SteamOS Gaming Mode with Decky Loader installed. If you still need Decky Loader, install it using its own installation instructions first.

## Install from a stable release

1. Open the [latest Decky Metadata release](https://github.com/beallio/Decky-Metadata/releases/latest) and download `Decky-Metadata.zip`.
2. Leave the ZIP file as it is. **Do not unzip it.**
3. In Gaming Mode, open the **Quick Access Menu** and select **Decky**.
4. Open Decky Loader settings and select **Developer**.
5. Under **Install Plugin from ZIP File**, select **Browse**.
6. Choose `Decky-Metadata.zip`, then select **Install**.

After installation, Decky Metadata appears in the Decky menu.

## Open Decky Metadata

Open the **Quick Access Menu**, select **Decky**, then choose **Decky Metadata**. The panel includes plugin settings and tools for your games.

To edit one non-Steam game, open that game's menu in your Steam library and select **Decky metadata...**. The editor lets you add a Steam match or change game details. See [Edit a game's metadata](editing-games.md) for matching, saving, and shortcut-name steps.

## If you cannot find the plugin

- Make sure Decky Loader is installed and that you are in SteamOS Gaming Mode.
- Check the Decky menu after installation; Decky Metadata appears there.
- Confirm that you selected the ZIP itself in **Browse** and did not unzip it first.

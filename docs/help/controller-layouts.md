# Controller layouts

For a non-Steam game with a saved Steam match, Steam's Controller Settings can include layouts from the matching Steam game. Depending on Steam's available configurations, this can include recommended, official, and community layouts. Decky Metadata supplements Steam's choices; your own layouts and Steam's templates remain available.

Open Controller Settings for the matched game and browse its available layouts as usual. If you want to change the source game, open **Decky metadata...**, choose the correct Steam match, and select **Save**. See [Get started](../../README.md#get-started) for how to open the editor.

## If matched-game layouts are missing

Confirm that the non-Steam game has the intended Steam match saved. Layouts from another game are not added to the current game's choices. Available recommendations and community layouts depend on what Steam has for the matched game; Decky Metadata cannot guarantee that every category has entries.

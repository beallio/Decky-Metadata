## Objective

Implement the `controller-type-filtering` plan: keep Steam's requested source
filter for normal and unknown controller types, force only the matched-source
query to unfiltered for the verified Legion Go S type `102`, and surface the

## Controller policy

- The controller is resolved solely by the `controllerIndex` from
  `QueryControllerConfigsForApp` arguments.
- Type `4` (Steam Deck), unknown, unavailable, and external/future types keep
  Steam's requested source filter.
- Type `102` (Legion Go S) is the sole entry in the explicit affected allowlist
  and changes only its supplemental matched-source query to `false`.
- Primary shortcut queries and Steam's visible
  `m_bFilterOtherControllerTypes` setting remain untouched. Steam's existing
  getter equivalence filter therefore continues to control visible results.
- The Versions panel samples `ControllerStore.GetControllers()` once at mount,
  prefers `ControllerStore` over `controllerStore`, and formats sorted unique
  types as diagnostics. It does not enumerate MobX stores or poll hot-plug
  changes.

  both the effective supplemental key and its Search classification whenever
  Steam queries that known source app natively. The affected regression covers
  shortcut (`true`) -> matched source (`false`) -> native source (`true`) ->

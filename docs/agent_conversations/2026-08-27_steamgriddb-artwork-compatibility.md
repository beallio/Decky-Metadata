# SteamGridDB artwork compatibility implementation — 2026-08-27

## Objective

Preserve the native shortcut identity for matched non-Steam shortcuts outside
their own Library Game Info route. This lets Steam's artwork resolver request
the shortcut icon on Library Home while preserving Decky Metadata's rich matched
Game Info behavior.

## Route and precedence decision

`BIsModOrShortcut` keeps Steam's native true value unless the call is for the
same matched shortcut on a recognized Library app/detail route. The order is:
native/non-shortcut pass-through, in-call launch truth, unmatched pass-through,
outside-detail pass-through, current-detail route shield, current-detail truth
window, then current-detail false spoof. Outside-detail calls do not consult a
route shield or decrement the bypass counter.

The live hard-reload check found `Router` absent in the SharedJSContext while
`window.location` still held the Game Info route. The fallback was necessary:
without it the strict classifier correctly saw no route, which also prevented
the matched Game Info quick-links row. The focused test reproduces this Steam
context shape.

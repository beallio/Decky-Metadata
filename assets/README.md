# Release screenshots

These images are captured from the visual Steam Gaming Mode CDP target with
`scripts/deck/screenshot.sh`, visually approved under `$TMPDIR/Decky-Metadata`, and
then copied here. Keep the stable filenames so README links remain reproducible.

- `decky-metadata-qam.png` — current Metadata controls, cropped to the native Quick Access popup.
- `decky-metadata-editor.png` — the metadata editor for Wobbly Life, a matched non-Steam game, with the **Find a Steam match** section above **Search IGN metadata**.
- `decky-metadata-shortcut-name.png` — the editor's shortcut-name preview with the **Use Steam name** button.
- `decky-metadata-gameinfo-top.png` — the Game Info page for Wobbly Life with SteamGridDB artwork, the HLTB times, the short description, developer, publisher, and release date.
- `decky-metadata-gameinfo-buttons.png` — the **SteamOS Compatibility** row (**Compatible**, as Steam shows it on a SteamOS device that is not a Steam Deck) and the **Store Page**, **DLC**, **Community Hub**, **Points Shop**, **Discussions**, and **Guides** buttons on the same page.
- `decky-metadata-trailers.webp` — animated: a Hades trailer plays in the header above the HLTB times and Play button.
- `decky-metadata-mini-achievements.png` — native achievement progress on a Steam game, from the verified live Gaming Mode capture.
- `decky-metadata-activity-news.png` — Steam Activity news for a matched shortcut.
- `decky-metadata-community.png` — Steam Community Content cards, a video and a screenshot, for the same matched shortcut.
- `decky-metadata-controller-layouts.png` — the Load new Layout screen on the **Community Layouts** tab for the same game.
- `decky-metadata-protondb-badges.png` — community tier icons on the real Library cover grid.
- `decky-metadata-store-row.png` — the Store info row on the Steam Store page for Brotato, with the **How Long To Beat** box and the **ProtonDB** box. Captured from the Store's own surface, so it is 1281×720 and has no Steam address bar.
